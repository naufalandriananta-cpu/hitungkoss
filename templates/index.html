04 • Sistem Prediksi & Sumber Data

Cara Kerja Model dan Data Acuan Madiun

Kenali algoritma prediksi, hasil pengujian, dan data yang digunakan sebagai acuan.

Teknologi & Algoritma yang Digunakan

  • Model Utama: {{ info_model.nama_model }} (Scikit-Learn) yang dibekukan ke model_kos.joblib.
  • Fitur Input (X): Jarak ke kampus (jarak_km), penilaian penghuni (rating), dan fasilitas AC terenkode biner (ac_num).
  • Backend & Database: Python Django 6 + SQLite (RiwayatPrediksi) untuk penyimpanan riwayat pencarian.
  • Layer Analisis AI: Engine Analisis Lokal Bawaan (berbasis statistik pasar Madiun) serta integrasi opsional API Groq (Llama 3.1) dan Google Gemini (2.5 Flash).
